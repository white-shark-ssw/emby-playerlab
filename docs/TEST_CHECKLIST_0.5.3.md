# 0.5.3 真机测试清单

测试设备：iPhone 15 Pro Max / iOS 17.0
测试媒体：Item 63368，传输层 AVPlayer，自动缓存模式。

## A. 自动续播

1. 正常播放 10 秒后左/右双击一次。
2. 确认新画面出现后无需点击播放按钮，时间持续前进。
3. 连续快速双击 10 次，确认每一次最终目标都会自动继续播放。
4. 拖动进度条到近处和远处各一次，确认松手后自动播放。
5. 手动暂停后再双击或拖动，确认仍保持暂停，不被自动续播。
6. 检查日志：允许出现 `AVPlayerResume retry`，但不应要求用户点击播放。

## B. 中途停滞恢复

1. 连续播放至少 3 分钟。
2. 若画面停住，不进行人工 Seek，观察约 4–8 秒是否自动恢复。
3. 日志应出现 `[Stall]` 与 `[AVPlayerRecovery]`；位置随后继续增长。

## C. 115 下载速度

1. 起播后记录 10、30、60、120 秒实时速度。
2. 若主速度持续低于约 8–14 MB/s，自适应阈值满足时应出现 `reconnect-slow-115`。
3. 重连后确认主连接从当前游标继续，不从头下载，不增加 `lane-probe`。
4. 确认没有因重连产生连续 403、重复 PlaybackInfo 刷新或播放中断。
5. 导出完整日志，重点保留每次 `reconnect-slow-115` 前后 20 秒。
