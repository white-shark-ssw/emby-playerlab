# 0.4.0 115AVIO 真机实验结论

测试资源：约 996 MB / 610 秒的 115 CDN MP4。

## 网络模式结果

| 模式 | 30 秒平均吞吐 | 观察到的瞬时峰值 |
|---|---:|---:|
| 单连接边下边写磁盘 | 6.36 MB/s | 22.87 MB/s |
| 单连接开放 Range | 5.91 MB/s | 17.14 MB/s |
| 独立双会话 | 5.82 MB/s | 12.03 MB/s |
| 单连接有限 Range | 5.51 MB/s | 12.94 MB/s |
| 共享会话双 Range | 4.13 MB/s | 9.82 MB/s |

所有实验均为 HTTP/1.1。共享双 Range 和独立双会话都出现明显的通道速度不均衡，并发没有稳定提高总吞吐。

## 播放结果

0.4.0 旧传输播放链的会话平均吞吐约 6.3 MB/s，最终有效缓存约 733 MB，缓存命中率约 99%。多数连续 Seek 在 65–100 ms 内显示新画面，说明当网络吞吐高于媒体消耗速度后，当前本机 HTTP 层可以保持流畅。

## 架构决策

0.4.1 正式播放路径采用：

```text
一个顺序主下载连接
→ 边接收边写稀疏文件
→ 本机 HTTP 只读已到达字节
→ 文件尾/Seek 未命中时最多临时增加一个辅助连接
```

不再默认长期运行三个条带式后台 worker。KSPlayer `AbstractAVIOContext` 桥接在下载优先数据层完成真机验证后继续实施。
