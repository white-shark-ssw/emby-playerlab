# 0.4.2

- 保留 0.4.1 下载优先单主连接架构。
- Seek 的时间比例估算仅用于投机预热，不再直接决定主连接迁移。
- `TransportHTTPServer` 把 AVPlayer 真实 Range 需求传入 `DownloadFirstMediaSession`。
- 实际阻塞的 `read(offset:length:)` 成为主连接迁移和缺口恢复的最高优先级依据。
- 主连接迁移采用约 300 ms 的真实需求收敛窗口，连续双击仍即时 Seek，但不会按照每次时间估算反复迁移。
- 辅助下载增加真实需求队列；一个辅助 Range 正在运行时，其他缺口排队处理，不再互相取消。
- 主连接到达 EOF/上限后检查近期真实需求区间；仍有缺口时自动从缺口继续。
- `PlayerController` Stall Watchdog 直接触发下载优先会话恢复；播放器等待时不允许因为主连接已到文件尾而长期 `active=0`。
- 新增主连接 4 秒滑动速度窗口和 8 MB 临时候选通道；低速且连续缓存不足时测速，候选显著更快才换线。
- 状态栏区分总缓存与当前位置连续缓存。
- Deployment Target 保持 iOS 15.0。
- 版本更新为 0.4.2（23）。
