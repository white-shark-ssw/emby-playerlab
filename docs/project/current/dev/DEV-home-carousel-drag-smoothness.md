# DEV-home-carousel-drag-smoothness

## Status

**Active**

- **Work ID**：`DEV-home-carousel-drag-smoothness`
- **Routing aliases / keywords**：轮播图滑动卡顿 / 轮播图丝滑 / 首页轮播 / carousel drag / carousel smoothness
- **Task**：优化 OnePlayer 首页 V3 轮播图的手动横向拖动体验，使手指持续拖动期间的画面位移连续、跟手，不出现明显冻结、追帧、抖动、跳变或掉帧感，并以用户提供的 EX 录屏作为体验对照。
- **User intent / acceptance criteria**：用户要求达到 EX 同级别跟手性：手指轻微横移时轮播图必须立即产生对应视觉位移；持续拖动、慢拖、快速拖、左右反向穿越中心点时都不能卡住、抖动、冻结后追帧或一次跳过一大段；松手后的完成/取消吸附仍应自然；不得破坏首页纵向滚动、自动轮播、详情点击、媒体行或播放器/P0 合同。
- **Accepted integration baseline**：当前真实 accepted runtime baseline 仍为 OnePlayer 0.14.11 / Build178，已合并到 `main`。Build179/180 轮播测试线继承已接受的 Build176 player episode-selection/session contract 与 Build178 canonical Emby episode ordering，不得倒退这些功能。
- **Build179 real-device result — FAILED**：用户于 2026-08-25 在 iPhone 15 Pro Max / iOS 17.0 安装 Build179 / OnePlayer 0.14.12 后提供新的 `轮播图卡顿.mp4`。用户明确报告：1）按住轮播图轻微移动时画面仍不动，需要累计一定距离才开始；2）一旦开始移动会出现明显的大段位移；3）先向一侧轻拖让相邻轮播出现一点，再立刻向另一侧反向时，会先卡住一下再突然移动一大段；4）与前面 EX 录屏相比仍明显不够跟手。该结果使 Build179 判定为 real-device tested / rejected，不能标记 stable。
- **New recording evidence**：新录屏约 9.5 秒、30 fps。逐帧检查可见多处“前一帧几乎静止 → 下一帧明显大幅变化”的节奏；与前面 EX 录屏的连续变化相比，Build179 仍存在交互性断点。该视频证据与源码状态机完全吻合，因此本轮没有先猜 GPU/图片解码。
- **Root cause refinement after Build179**：Build179 已把高频 transition state 从首页根 `@State` 隔离出去，但真实源码仍保留两类确定死区：1）`DragGesture(minimumDistance: 4)` 且 `onChanged` 再要求 `abs(horizontal) > 4`，导致轻微移动不会进入 progress；2）`carouselBackdropBlendProgress` 对原始 progress 先减去 `0.08` 再 smoothstep，使主轮播图片前 8% progress 天然没有视觉响应。更关键的是，原横向 dominance guard 每次 `onChanged` 都重新判断；当手指从一侧反向穿越中心、水平 translation 接近 0 时，vertical 微小噪声/4 pt gate 会让 progress 暂停更新，随后越过阈值后再跳到另一侧，直接对应用户描述的“卡住一下再大段位移”。
- **Build180 implementation**：第二版仅在 Build179 已验证的局部 carousel owner 上修正手势/视觉 progress：1）`DragGesture.minimumDistance` 改为 0；2）横向 dominance 只在尚未建立 carousel drag 时用于初次锁定，一旦 `isCarouselDragging` 为 true，后续包括反向穿越中心点的更新都不再重新套方向死区；3）移除 `abs(horizontal) > 4` 绝对位移 gate；4）`carouselBackdropBlendProgress` 改为直接 clamp 原始 progress，不再丢掉前 8% 或 smoothstep 小位移；5）保留 Build179 的单一 `V3HomeCarouselTransitionState` owner、局部 transition scope、原 commit/cancel 阈值、0.22/0.18 秒 settle 动画、6 秒自动轮播、0.62 秒自动过渡、blur 设计和纵向滚动结构；6）不加入 debounce/throttle/retry/fallback/timer/watchdog。
