# 真机测试清单

## A. 基础连接

- [ ] 公网 HTTPS 入口可以读取 `/System/Info/Public`
- [ ] 可以登录 Emby 4.8.10.0
- [ ] 杀掉 App 后 Token 仍能恢复
- [ ] 主动退出后 Token 被清除

## B. STRM / 302

- [ ] PlaybackInfo 返回媒体源
- [ ] 播放入口触发 NAS STRM 替换项目
- [ ] 最终视频从网盘/CDN 加载
- [ ] 拖动后收到 206 或仍能正常续播
- [ ] 退出重进后临时链接可重新获取

## C. 双击 Seek

- [ ] 左侧双击立即快退
- [ ] 右侧双击立即快进
- [ ] 连续双击不等待累加防抖
- [ ] 目标在缓冲内时无明显加载圈
- [ ] 设置页修改秒数立即生效
- [ ] 暂停状态双击后保持暂停
- [ ] 播放状态双击后继续播放

## D. 提前 EOF

- [ ] 正常影片结尾能正确停止
- [ ] 异常短片刚开始收到结束事件时不自动关闭页面
- [ ] 页面显示“疑似提前结束”
- [ ] 日志包含当前位置、Emby 时长、AVPlayer 时长

## E. Emby 进度

- [ ] 开始播放后服务器出现活动会话
- [ ] 正常播放约每 10 秒上报
- [ ] 双击后立即上报新位置
- [ ] 暂停后立即上报
- [ ] 退出后保存最后位置

## F. 日志安全

- [ ] 日志不出现密码
- [ ] 日志不出现完整 AccessToken
- [ ] URL 中 api_key/token/signature 已脱敏
- [ ] Cookie/Authorization 已脱敏
