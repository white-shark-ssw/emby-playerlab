# 0.7.0 真机测试清单

## 构建与安装

- [ ] Validate Source 通过。
- [ ] Build Unsigned IPA 通过。
- [ ] IPA 可在 iPhone 15 Pro Max / iOS 17.0 通过 TrollStore 安装。
- [ ] 构建报告中 KTVHTTPCache、CocoaAsyncSocket 及所有 Framework 的 MinimumOS 不高于 iOS 15.0。

## 基线配置

- 传输实现：KTVHTTPCache 持续预取。
- 缓存位置：自动或磁盘。
- 磁盘缓存预算：大于测试视频体积。
- 持续预取：开启。
- 蜂窝持续预取：按测试网络决定。
- 退出后保留缓存：第一轮关闭，第二轮开启。

## 63368 异常 MP4

- [ ] 播放页显示 `AUTO·KTV`。
- [ ] 首帧与声音正常。
- [ ] 下载速度在播放后持续存在，不因达到短缓冲窗口而停止。
- [ ] 能跨过过去的异常位置。
- [ ] 连续双击不少于 30 次，Seek 仍可恢复。
- [ ] 出现缓冲警告后不切换引擎。
- [ ] 等待后能继续播放且 App 不闪退。
- [ ] 缓存量最终接近文件体积或出现 `completeFile=true`。

## 连续两次播放

- [ ] 第一次关闭“退出后保留”，退出后再次播放不会错误复用旧缓存。
- [ ] 第二次开启“退出后保留”，再次播放能复用已缓存片段。
- [ ] 两次之间杀掉并重新打开 App，不出现 localhost 端口失效。
