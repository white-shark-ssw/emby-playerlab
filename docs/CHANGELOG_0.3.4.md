# 0.3.4

- 修复 0.3.3 日志中 90 次 `TransportRefresh` 与 51 次重复 302 解析造成的刷新风暴。
- 115 单次 403/410 先对当前最终地址重试一次；确认失败后才刷新 PlaybackInfo。
- PlaybackInfo/302 刷新采用 single-flight，同一时刻只允许一个刷新任务。
- 初次 302 解析也采用 single-flight，避免本机 HTTP 多连接同时重复解析。
- 本机 HTTP 监听器不再等待 302 解析完成后才启动，AVPlayer 初始化与解析并行。
- 首个播放器读取完成前不启动大规模头部预加载，避免抢占启播关键请求。
- 顺序播放期间保持一个稳定预加载窗口，不再每移动约 4 MB 就取消并重建。
- Seek 时取消低优先级预加载，并按目标时间估算字节位置启动新窗口。
- 后台预加载保留至少两路连接给播放器紧急读取。
- Range 分片继续允许选择 1/2/4/8/16 MB，默认保持 1 MB 以兼顾启播。
- 缓存统计改为有效唯一缓存；自动模式不再把同一数据的内存与磁盘副本重复相加。
- 缓存命中率按实际服务字节统计。
- 新增 5 秒实时下载速度，保留全会话平均速度。
- 本机 HTTP 在响应已开始后发生客户端主动断连时不再追加无效 502 响应。
- 版本更新为 0.3.4（19），Deployment Target 保持 iOS 15.0。
