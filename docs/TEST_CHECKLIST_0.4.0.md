# 0.4.0 115AVIO Lab 测试清单

## 准备

1. 安装 0.4.0 IPA 并登录 Emby。
2. 输入测试 ItemId，加载媒体信息。
3. 在目标媒体源下点击“115AVIO 实验”。
4. 确认页面显示文件大小、HTTP Range 支持和 115 CDN 识别结果。

## 推荐第一轮

- 请求头：沿用 302 请求头。
- 单项持续时间：30 秒。
- 有限 Range：256 MB。
- 点击“依次运行全部模式”。
- 测试期间不要启动正式播放器，也不要切换网络。

## 第二轮

使用相同参数，把请求头改成“115 最小请求头”，再次运行全部模式。

## AVIO 自检

点击“运行 read / seek / fileSize 轨迹”，确认：

- 文件头连续读取两次；
- 能跳到文件中部读取；
- 能跳回 1 MB 位置读取；
- 每次读取的 resultingOffset 正确递增；
- 临时网络失败不会被记录为 EOF。

## 导出

导出 JSON 实验报告和常规诊断日志。报告中不应包含最终签名 URL、Cookie、Emby Token 或完整私有请求头。

## 重点比较

- 单长连接是否明显快于有限 Range；
- 共享双连接是否能叠加吞吐；
- 独立双会话是否比共享会话更慢或更容易 403；
- 边写磁盘与纯接收的差距；
- 两种请求头配置是否造成显著差异；
- HTTP 协议是否为 h2 或 http/1.1；
- 连接复用是否发生。
