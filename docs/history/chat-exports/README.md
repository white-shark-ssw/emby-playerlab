## 正常接手不要通读历史

新会话从这里开始：

`docs/project/START_HERE.md`

然后读取 `docs/project/` 的当前权威资料。

只有需要追溯某个旧 Build、失败实验、旧日志或历史推理时，才读取相应 vXX 原文。

## 重要警告

历史导出包含：

- 后来被推翻的推测；
- 只计划但未实现的方案；
- CI 成功但真机失败的版本；
- 已经退出正式架构的实验代码。

因此历史原文是**证据**，不是当前规格。当前状态以 `docs/project/` + 实际源码 + 最新真机结果为准。
